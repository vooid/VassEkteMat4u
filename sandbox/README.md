# Sandbox

Throwaway samples used to check that the repo works. Not part of the Ekte Mat system.

| File | What it does | Run it |
|---|---|---|
| `fibonacci.cpp` | Prints the first N Fibonacci numbers (N = 0–94, from argument or prompt) | `c++ -std=c++17 -o fib fibonacci.cpp && ./fib 10` |
| `hello.bf` | Prints "Hello World!" in [Brainfuck](https://esolangs.org/wiki/Brainfuck) | Paste into an online interpreter, e.g. https://copy.sh/brainfuck/ |
