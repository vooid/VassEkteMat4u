# Requirements

User stories with acceptance criteria.

- [`user_stories.md`](user_stories.md): 31 stories in 8 epics, with MoSCoW priority and sources.
- [`basic_desc.txt`](basic_desc.txt): the team's functional requirements description.
- [`requirements.txt`](requirements.txt): report of all requirements (sources, constraints, stories with status, open questions).
- [`technology.txt`](technology.txt): the technology used in the build (Flask, Neo4j, Python packages and versions, tools).

Story template:

```
### US-<nr>: <short title>
As a <role>, I want <goal> so that <benefit>.
Source: <interview/file>
Acceptance criteria:
- Given <context>, when <action>, then <outcome>.
```
