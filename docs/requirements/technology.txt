EKTE MAT ORDERING SYSTEM - TECHNOLOGY
Status as of 2026-10-27

Installable Python packages: backend/requirements.txt  (pip install -r requirements.txt)
Local database:              docker-compose.yml
Setup and running:           backend/README.md


1. REQUIRED BY THE PROJECT
--------------------------
- Flask for the backend (CLAUDE.md)
- Neo4j for data storage (CLAUDE.md)
- Server-rendered Flask templates, no separate JavaScript app (decision 2026-10-27)

5. FRONTEND (in the browser)
----------------------------
- HTML from Jinja2 templates (backend/app/templates/), one stylesheet (backend/app/static/style.css).
- No JavaScript framework and no external scripts or fonts at runtime.
- Small inline JavaScript only on the kitchen pages, plus a service worker
  (backend/app/static/kitchen-sw.js) that keeps the kitchen screen readable offline (US-29).
- Map links open Google Maps in the driver's own app; nothing is loaded from Google by the site.


6. FLASK COMMAND-LINE COMMANDS (backend/app/cli.py, backend/scripts/)
---------------------------------------------------------------------
flask create-staff     Create an admin, kitchen or driver account
flask set-pin          Set a kitchen or driver PIN
flask run-daily-jobs   7-day reminder and 5-day lock (run once a day, e.g. with cron)
python -m scripts.seed Constraints, event types, allergens, diets, sample dishes and recipes


7. SECURITY MEASURES BUILT ON THE ABOVE
---------------------------------------
- Passwords and PINs hashed with Werkzeug (never stored in plain text).
- CSRF tokens on all forms (Flask-WTF).
- Session cookie: HttpOnly, SameSite=Lax, Secure when served over HTTPS.
- PIN login only on admin-approved devices; only the SHA-256 hash of the device token is stored.
- Secrets in backend/.env, which git ignores. The Claude API key is never published (CLAUDE.md).
